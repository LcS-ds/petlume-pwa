# PetLume Pet Shop Escola

Projeto escolar de um site PWA responsivo para um pet shop fictício.

## Recursos

- instalação como aplicativo;
- funcionamento offline após a primeira visita;
- layout adaptado para celular e computador;
- formulário demonstrativo de agendamento;
- manifesto, service worker e ícones próprios.

> Todos os nomes, contatos, endereços, serviços e preços são fictícios e usados somente para fins educacionais.
